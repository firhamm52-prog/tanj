# Detail produk dan produk disukai

Popup detail produk menampilkan galeri, panel thumbnail putih bergaris hitam, tombol hati, dan tab Description, Care Instructions, Details, serta Shipping. Tab aktif diberi garis bawah. Tidak ada tab sizing; ukuran All Size tetap ditampilkan.

CMS → Produk/Hijab → Edit → **Deskripsi & perawatan produk**: isi Description, Care Instructions, atau Shipping (masing-masing maksimal 2000 karakter), lalu simpan dan publikasikan. Jika belum diisi, website menggunakan deskripsi koleksi atau pesan bahwa detail akan ditambahkan. Details mengambil nama, warna, dan ukuran produk.

Customer menekan hati pada detail produk untuk menyukai/membatalkan suka. Ikon hati di header membuka daftar produk disukai. Daftar menyimpan ID varian pada browser, bertahan setelah refresh, dan mengikuti perubahan pada tab browser lain. Harga serta ketersediaan tetap mengikuti katalog terbaru; daftar tidak tersinkron antarperangkat atau akun.

Perubahan ini tidak memerlukan SQL tambahan, perubahan Midtrans, atau template email.
